# M1 - Requirement, Specification va Architecture C04

## 1. Chuc nang cua de tai

C04 la bo canh bao hai nguong co vung tre hysteresis.

Neu sample_in >= high_th thi bat canh bao.

Neu sample_in <= low_th thi tat canh bao.

Neu low_th < sample_in < high_th thi giu nguyen trang thai canh bao truoc do.

Co che hysteresis giup tranh hien tuong canh bao bat/tat lien tuc khi gia tri dau vao dao dong quanh nguong.

Vi dau ra trong vung tre phu thuoc vao trang thai truoc do nen C04 la mach tuan tu va can phan tu nho.

## 2. Giao dien cua c04_core

- clk: input 1 bit, clock, cap nhat tai canh len.
- rst_n: input 1 bit, reset dong bo tich cuc muc thap.
- sample_in: input 8 bit unsigned, gia tri mau hien tai, mien 0 den 255.
- low_th: input 8 bit unsigned, nguong duoi.
- high_th: input 8 bit unsigned, nguong tren.
- alert: output 1 bit, 1 la canh bao ON, 0 la canh bao OFF.

## 3. Clock va reset

Mach cap nhat trang thai tai posedge clk.

rst_n la reset dong bo active-low.

Khi rst_n = 0 tai canh len clock, alert duoc dua ve 0.

## 4. FSM

C04 co 2 trang thai:

S0 - OFF:
alert = 0.

S1 - ON:
alert = 1.

Dieu kien chuyen:

OFF -> ON khi sample_in >= high_th.

ON -> OFF khi sample_in <= low_th.

Khi low_th < sample_in < high_th thi giu nguyen trang thai.

Vung hysteresis KHONG phai trang thai thu ba.

## 5. State

State cua C04 duoc luu ngay trong Flip-Flop cua tin hieu alert.

alert = 0 tuong ung OFF.

alert = 1 tuong ung ON.

Vi FSM chi co 2 trang thai nen can 1 bit state.

Du doan truoc synthesis: neu chi synthesis c04_core thi mach can 1 Flip-Flop de luu alert.

## 6. So do khoi

sample_in, low_th va high_th duoc dua vao cac khoi so sanh:

- sample_in >= high_th
- sample_in <= low_th
- low_th < high_th

Ket qua so sanh ket hop voi trang thai alert hien tai de quyet dinh alert tiep theo.

Trang thai tiep theo duoc luu vao Flip-Flop tai canh len cua clk.

## 7. Cac truong hop bien can kiem tra

Voi low_th = 50 va high_th = 100:

- sample = 99 khi OFF -> alert = 0.
- sample = 100 khi OFF -> alert = 1.
- sample = 90 khi ON -> alert van = 1.
- sample = 51 khi ON -> alert van = 1.
- sample = 50 khi ON -> alert = 0.
- sample = 0 va 255 -> kiem tra bien cua du lieu 8 bit.
- low_th >= high_th -> thiet ke hien tai giu nguyen trang thai.
- rst_n = 0 -> alert ve 0 tai canh clock.

## 8. Kien truc thay the

Co the su dung mach canh bao mot nguong thuan to hop:

alert = (sample_in >= threshold).

Mach nay don gian va khong can Flip-Flop, nhung khi dau vao dao dong quanh threshold thi alert se bat/tat lien tuc.

Vi vay C04 chon kien truc hai nguong co 1 bit nho de tao hysteresis.

## 9. Van de giao dien Tiny Tapeout

Giao dien c04_core hien tai co sample_in 8 bit, low_th 8 bit, high_th 8 bit, clk, rst_n va alert.

Neu tinh truc tiep thi giao dien core vuot ngan sach 24 chan Tiny Tapeout.

Charter mo ta phuong an dung mot bus threshold 8 bit de nap low_th va high_th theo nhieu chu ky.

Van de wrapper/Tiny Tapeout can duoc xac nhan voi giang vien truoc khi thay doi top-level.
